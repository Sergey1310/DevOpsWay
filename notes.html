S05 · Docker
Контейнер падает exit 137
OOM Kill — нет лимитов памяти или лимит слишком мал. Проверь: docker stats, docker inspect → HostConfig.Memory
docker stats · docker inspect · dmesg
S08 · CI/CD
CI зелёный, деплой не идёт
Environment protection rule / required approval не выполнен. Или secrets не пробрасываются в environment. Проверь: Actions → Environments → Protection rules.
GitHub Actions logs · env secrets audit
S12 · Terraform
Terraform state lock error
Параллельный apply или упавший предыдущий оставил lock в DynamoDB. Проверь: terraform force-unlock <LOCK_ID>. Убедись что нет другого apply.
terraform force-unlock · AWS DynamoDB console
S19 · K8s
Pod застрял в Pending
Нет ресурсов (CPU/memory requests превышают доступные), неверный nodeSelector/taints, PVC не bound. Проверь: kubectl describe pod → Events секция.
kubectl describe pod · kubectl get nodes -o wide
S19 · K8s
Service недоступен внутри кластера
Selector mismatch между Service и Pod labels — самая частая причина. Проверь: kubectl get endpoints <svc> — если пусто, selector не совпадает.
kubectl get endpoints · kubectl get pods --show-labels
S19 · K8s
DNS resolution fails в поде
CoreDNS не работает или NetworkPolicy блокирует UDP 53. Проверь: kubectl exec -it <pod> -- nslookup kubernetes.default. Logs: kubectl logs -n kube-system -l k8s-app=kube-dns
nslookup · kubectl logs CoreDNS · dig
S04 · Linux
Сервис недоступен по сети
iptables DROP правило, неверный маршрут, или MTU mismatch. Порядок диагностики: ping → traceroute → ss/netstat → iptables -L → ip route
ping · traceroute · ss · iptables -L · ip route
S19 · K8s
CrashLoopBackOff
Неверный CMD/entrypoint, missing env var, failing readiness probe, OOMKilled. Проверь: kubectl logs <pod> --previous и kubectl describe pod → Last State.
kubectl logs --previous · kubectl describe pod
